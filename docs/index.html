额度在手机里，活儿在电脑上

12 个月、每月 100 亿 token。这笔东西没少，只是落在了一块不干活的屏幕上。

STEPX Neo 先行版 3999 元，捆 12 个月、每月 100 亿 token。按阶跃开放平台同量级套餐价粗算，这份额度本身接近三千。

但它只认手机里的 Amoo。官方没给 API Key，电脑上的客户端连不上。你花钱买的东西，落在了一块不干活的屏幕上。

手机上问零碎问题确实方便。写长一点就难受：改一段话要长按、选中、拖动，手指一抖就选多了；聊到十几轮想翻前面的记录，得一直往上滑。投屏试过，延迟能感觉到；把回答复制进文档接着写，上下文又断了，每次都得把前情再贴一遍。

Amoo 是在手机里跑的，电脑缺的只是一个入口。Amoo Bridge 把这个入口开出来。额度没搬家，只是从在手机里花，变成在电脑前花。

它不会改变的事
  • 额度仍在手机里扣，计量以官方为准
  • 不登录你的账号，不修改 Amoo
  • 不绕过任何额度或付费机制
  • 请求只在本机走，不经过第三方服务器

它只做一件事：在电脑上开一个网关

不开新账号，不搬额度，也不改 Amoo。只是让客户端发出的请求，能走到手机里。

客户端填三行

地址、API Key、模型名，窗口里给现成的，不用自己拼。Chatbox、Cherry Studio、WorkBuddy、Cline、Aider 填的都是这三行。

断了会自己接

插头松了、手机睡过去，它自己重连，不用重开程序，也不用重新填配置。

网关只在这台电脑上

它是一个跑在 Windows 上的程序，网关只监听本机回环地址，外面连不进来，拔了网线也能用。

请求经 USB 进手机

客户端发出的请求送到手机里的 Amoo，回答原路回来。对话不落盘，程序不留记录。

顺手做掉的还有：窗口关掉网关照跑，不必一直开着窗口；端口被别的程序占了，它自己换一个，界面上的地址跟着变；重复打开只唤起一个窗口，不会起两个网关；手机省电设置只动两项，随时能恢复；MCP 接外部工具，可选，默认收起。

从插线到发出第一条消息

第一次大概两分钟。之后每次用，只要插上线。

先准备
  • Windows 10 / 11 64 位电脑
  • 一台 STEPX Neo，装好 Amoo，开启 USB 调试
  • 一根能传数据的 USB 线（只能充电的不行）
STEP 01

插线，点「一键连接手机」

用 USB 线把手机插到电脑上，打开 Amoo Bridge，点绿色按钮。手机上弹出「允许 USB 调试」时选允许。

USB 调试这步头一回要弄，之后不用再管。顶部出现「手机 已连接 · awake」，说明这头通了。

STEP 02

点「下一步：填模型」，抄下三行

窗口里直接给出三个值，不用自己拼地址：

Base URL API Key 模型名
STEP 03

粘进客户端，发条消息

在 Chatbox、Cherry Studio 或 WorkBuddy 里新建一个 OpenAI 兼容模型，把三行粘进去，发一句话。

收到回复就算通了，之后窗口最小化到托盘就行。
