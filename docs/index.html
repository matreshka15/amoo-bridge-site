把手机上的 Amoo
接到这台电脑。

Amoo Bridge 在本机开一个网关，让 Chatbox、Cherry Studio、WorkBuddy 等客户端 直接使用手机上的 Amoo。也可以按需接入 MCP，把手机能力当成工具调用。

三种用法，按需要选

普通聊天只需要模型地址；MCP 是给进阶用户的，不用不装。

OpenAI 兼容端点

在任意支持 OpenAI 接口的客户端里填三行：Base URL、API Key、模型名。

MCP（可选）

让 WorkBuddy / Claude Desktop 直接查手机会话、读历史、发消息。普通聊天不需要。

本地网关

只监听 127.0.0.1，不经过第三方服务器；托盘常驻，断线自动重连。

三步开始

不用记命令，跟着向导点就行。

1

手机用数据线连电脑，打开 USB 调试并允许这台电脑。

2

桌面端点“一键连接手机”，等待网关启动。

3

在“模型”页复制三行地址，粘贴到聊天客户端。
