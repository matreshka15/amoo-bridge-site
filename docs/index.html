客户端只认一种接口，手机那头没开

于是中间这一层，得有人补上。

改一段八百字的稿子，你在电脑上开好了编辑器，手指却要伸向手机：原文复制进 Amoo，等回复，再复制回来。改一轮四次，改三轮十二次。

手机上问出来的话，在电脑上找不到；电脑上整理好的上下文，手机里接不上。想把 Amoo 接进 Cursor 或者 VS Code，会发现它连一个能填的地址都没有。

Amoo Bridge 补的就是这一层。手机还是那台手机，客户端里多一个能选的模型来源。它不提升 Amoo 的能力，只把"要拿手机"这件事去掉。

它不做什么
  • 不修改 Amoo 本身
  • 不绕过账号、额度与付费机制
  • 不经过我们的服务器，也没有账号体系
  • 不提供模型，也不代理任何第三方服务

连接这件事，它替你盯着

从插上线到发出第一条消息，容易出错的环节都处理过了。

三步向导

连手机、填模型、发一条测试消息。窗口里写着下一步点哪里，不用翻文档。

断线自动重连

线松了、手机睡过去，它自己接回来，不用你重开一遍。

托盘常驻

窗口关了网关照跑。你不必为了用它，一直开着一个窗口。

端口冲突自动避让

默认端口被别的程序占了，它换一个接着跑。你看不到报错，也犯不着去改设置。

顺手做掉的还有：配置完当场发一条消息验证；重复打开只唤起一个窗口，不会起两个网关；手机省电设置只动两项，随时能恢复；MCP 接外部工具，可选，默认收起。

从插线到发出第一条消息

第一次大概两分钟。之后每次用，只要插上线。

先准备
  • Windows 10 / 11 64 位电脑
  • 手机装好 Amoo，开启 USB 调试
  • 一根能传数据的 USB 线（只能充电的不行）
STEP 01

插线，点「一键连接手机」

用 USB 线把手机接到电脑，打开 Amoo Bridge，点绿色按钮。手机上弹出「允许 USB 调试」时选允许。

顶部出现「手机 已连接 · awake」，说明这头通了。

STEP 02

点「下一步：填模型」，抄下三行

窗口里直接给出三个值，不用自己拼地址：

Base URL API Key 模型名
STEP 03

粘进客户端，发条消息

在 Chatbox、Cherry Studio 或 WorkBuddy 里新建一个 OpenAI 兼容模型，把三行粘进去，发一句话。

收到回复就算通了，之后窗口最小化到托盘就行。

十次里九次卡在第 1 步：手机没开 USB 调试，或者用的是只能充电的线。先确认这两件事，再点连接。

关于这个软件

有些话写在前面，省得彼此误会。

性质

独立第三方工具，不是 Amoo 官方产品，与官方没有隶属、合作或背书关系。

许可与版本

闭源付费，买的是个人使用许可。当前 v3.7.3，改动都记在 GitHub 的提交记录里。

换客户端不用换工具

走的是 OpenAI 兼容标准。今天用 Chatbox，明天换 Cursor，这套配置照样能用。

已知限制
  • 只支持 Windows 10 / 11 64 位，Mac 与 Linux 没有时间表
  • 无线模式会掉线，日常建议插线
  • 手机端必须开 USB 调试，只能充电的线不行

上手前，先看这几条

按你最可能担心的顺序排的。

需要会写代码吗？

不需要。装好打开，按「三步向导」点下去就行，全程没有命令行，也不用编辑配置文件。

支持哪些客户端？

凡是支持 OpenAI 兼容接口的工具都能用。常见的有 Cherry Studio、Chatbox、NextChat、LobeChat、沉浸式翻译、Cursor、VS Code（Cline / Continue）、Obsidian 插件。填的都是同样三行：Base URL、API Key、模型名。

会不会影响我 Amoo 的账号？

这个工具不登录你的 Amoo 账号，也不修改 Amoo 本身，只在你本机把客户端发出的请求经 USB 转给手机上的 Amoo。它不绕过任何额度或付费机制。至于这样做是否合规，取决于 Amoo 的使用条款，我们不做承诺，你可以自己判断。

我的对话会经过你们的服务器吗？

不会。网关只监听本机，请求经 USB 直接到手机。我们没有可以中转的服务器，也看不到你的对话内容。

手机一定要用线连着吗？

默认走数据线，最稳；线必须能传数据，只能充电的不行。想在局域网里用无线，可以在「高级设置」取消「只用数据线」，按说明连一次无线调试；无线会掉线，日常还是建议插线。

连接断了怎么办？

会自动重连。一直连不上，就重新插一下线，或者到「诊断」页看状态。

端口被占用了怎么办？

不用管，程序会自动换一个可用端口。

支持 Mac 或 Linux 吗？

当前版本只支持 Windows 10 / 11 64 位，其他平台还在评估。

¥14.9 值不值？

如果你每天在电脑前用 AI，又常常为了问一句话去摸手机，值。如果你一周用不了几次，或者手机上问就够了，那这钱可以省下来，不用买。

以后不更新了怎么办？

接口走的是 OpenAI 兼容标准，客户端换了你不用换工具；手机端要是改了，会先在提交记录里说明。风险没法承诺为零，但这一层做得很薄，真出问题改动也小。

为什么下载不到安装包？

源码和安装包不公开，按订单人工发放。按上面「获取软件」扫码付款后发邮件确认即可。
