先准备
  • Windows 10 / 11 64 位电脑

STEP 01

插线，点「一键连接手机」

用 USB 线把手机接到电脑，打开 Amoo Bridge，点绿色按钮。手机上弹出「允许 USB 调试」时选允许。

顶部出现「手机 已连接 · awake」，说明手机这头通了。

STEP 02

点「下一步：填模型」，复制三行

窗口里会直接给出三行配置，复制它们：

Base URL API Key 模型名
STEP 03

粘进客户端，发条消息

在 Chatbox、Cherry Studio 或 WorkBuddy 里新建 OpenAI 兼容模型，粘贴三行，发一句话。

收到回复就通了，之后窗口最小化到托盘就行。

卡住了就点窗口右上角的「不会用？看三步向导」，跟着重新走一遍。

上手前，先看这几条

需要会写代码吗？

不需要。装好打开，按「三步向导」点下去就行，全程没有命令行。

MCP 是什么？必须开吗？

MCP 是进阶功能，给需要接入外部工具的人用。普通聊天完全不需要，界面里默认收起。

支持 Mac 或 Linux 吗？

当前版本只支持 Windows 10 / 11 64 位。

手机一定要用线连着吗？

需要一根能传数据的 USB 线把手机接到电脑，只能充电的线不行。

连接断了怎么办？

桌面端会自动重连。如果一直连不上，重新插一下数据线，或到「诊断」页看看状态。

端口被占用了怎么办？

不用管，程序会自动换一个可用端口。

支持哪些客户端？

凡是支持 OpenAI 兼容接口的客户端都可以，例如 Chatbox、Cherry Studio、WorkBuddy。填的都是同样三行：Base URL、API Key、模型名。

为什么下载不到安装包？

源码和安装包不公开，按订单人工发放。按上面「获取软件」发邮件即可。
